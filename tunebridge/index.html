      Links and files

      What can I paste or drop?

      Everything is read in this browser and nothing is uploaded. Pasting a link works for public playlists and albums; the files below are for private playlists or whole libraries.

      Spotify
      Paste the playlist link (Share → Copy link to playlist). For private playlists or your whole library: spotify.com/account/privacy → Download your data → request Account data; Spotify e-mails a ZIP within a few days — drop the whole ZIP here (Playlist1.json, YourLibrary.json). Exportify CSVs work too.
      Apple Music
      Paste the playlist link (Share → Copy Link). Or, in the Music app, select a playlist and choose File → Library → Export Playlist… (XML is best, Plain Text works) and drop the file here.
      YouTube Music
      Paste the playlist link (⋮ → Share). The playlist must be Public or Unlisted. For your liked songs: takeout.google.com → YouTube and YouTube Music → music-library-songs and drop the CSV / ZIP here.
      SoundCloud
      Paste the link of a public playlist (Share → Copy link).
      TIDAL
      Paste the link of a public playlist or album (Share → Copy playlist link).
      Deezer
      Paste the link of a public playlist or album (Share → Copy link).
      Anything else
      A CSV with title and artist columns (Soundiiz, TuneMyMusic, a spreadsheet), an M3U / M3U8 file, or a plain text file with one song per line as Artist – Title.

      Site owner settings

      Service registrations

      Visitors never see this. The destination services need TuneBridge registered once (config.js, instructions in SETUP.md). Values entered here are stored only in this browser and override config.js — handy for testing before you publish.

      About

      TuneBridge is a bridge, not a vault.

      You paste the link of a public playlist (or drop a file you exported). TuneBridge reads the songs, finds the same ones on the destination service (by ISRC first, then title, artist and duration) and rebuilds the playlist there after you log in — on that service’s own website, with the login you always use. TuneBridge never sees your password and nothing is uploaded to a TuneBridge server: there isn’t one.

      What can go where?

      Good to know

      • Matches are never perfect: regional catalogs differ, and some uploads only exist on one service. Every transfer ends with a list of what could not be found, which you can download as CSV.
      • Public pages only show a playlist’s first songs on some services (Spotify, Apple Music). For very long playlists, drop an exported file instead.
      • YouTube’s API quota limits how many songs can be added to YouTube Music per day (about 60 with the default quota).
