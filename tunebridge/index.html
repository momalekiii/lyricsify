      About

      TuneBridge is a bridge, not a vault.

      Everything happens in your browser: you sign in with each service directly, TuneBridge reads your library through the official APIs, finds the same songs on the other side (by ISRC first, then title, artist and duration) and recreates your playlists there. Nothing is uploaded to a TuneBridge server, because there isn’t one.

      What can move where?

      Good to know

      • Matches are never perfect: regional catalogs differ, and some uploads only exist on one service. Every transfer ends with a list of what could not be found, which you can download as CSV.
      • YouTube’s API quota limits how many tracks can be added to YouTube Music per day (about 60 with the default quota).
      • Apple Music needs an Apple Developer membership on the site owner’s side; Spotify apps in development mode must allow-list users. See the README for setup details.
